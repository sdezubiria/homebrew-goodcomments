# Homebrew tap for GoodComments

```bash
brew install sdezubiria/goodcomments/goodcomments
```

Installs the `gc` command, builds the GoodComments menu bar app and sets up a `brew services` entry for the server. Then:

```bash
open "$(brew --prefix goodcomments)/libexec/mac/build/GoodComments.app"
```

Update with `brew upgrade goodcomments`. See [GoodComments](https://github.com/sdezubiria/goodcomments) for everything else.
